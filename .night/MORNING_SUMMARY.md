## 바뀐 화면
- **사기 전 결정 플로우(N7, 신규)**: 홈 '사기 전에 두 세계 비교하기' → 숫자패드로 금액·빈도 → 미래 비용 3숫자(이번 달 / 다음 결제일 / 1년 뒤) → 참기·더 싸게·사기 → 결과. 참은 돈은 자유 저축으로 옮기고 바로 예금·적금 가입으로 이어짐.
- **모으기 탭(신규)**: 모은 돈 합계, 만기 임박 D-day, 내 계좌 목록, 가상 은행 4곳 상품 6종.
- **상품 상세 → 4단계 가입**: 설명 → 약관 요약 → 금액·기간 → 확인. 기본/우대금리, 단리·월복리, 세후(15.4%) 수령액.
- **계좌 상세**: 토스식 계좌 카드, 기간 진행 바, 적금 회차 캘린더(납입/미납/예정), 우대조건 달성 여부, 중도해지 시 놓치는 이자.
- **거래내역 필터**: 전체 / 넣은 돈 / 받은 돈 / 이자. 이자는 세전·세금·세후로 나눠 보여 줌.
- 가상 지갑에 월급 주기(매달 1일 +80만, 고정지출 −53만) 반영.

## 엔진
- `src/lib/bank`: 원 단위 정수, 불변 거래 원장, 자동이체·미납·만기·중도해지, 데모용 시간 이동. vitest로 계산 검증.
