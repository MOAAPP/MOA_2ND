# v11 모의투자 중복 안내 제거

## 변경 내용
- `src/screens/Learn.tsx`의 `Practice` 모의투자 화면 상단에서 ‘생활비에서 투자할 돈을 나눠보고 싶다면?’ 안내 카드 및 ‘생활비 연동’ 이동 버튼을 제거.
- 같은 화면 하단의 소액 ETF 연습 경로 안내 문장도 제거.
- 기존 주식 시세 API, 종목 검색, 관심종목, 실시간/지연 표기, 종목 상세, 가상 매수·매도, 주문·보유종목, 디스코드 카드뉴스 기능은 변경하지 않음.
- 기존 가상자산 대시보드, 예·적금, 평행세계 비교, 금융학습도 변경하지 않음.

## 범위 참고
- 본 수정은 사용자 요청이 지목한 **모의투자 탭의 중복 안내·이동 버튼 제거**에 한정.
- 홈 자산 구성 및 기존 가상 장부의 투자 잔액은 그대로 남아 있으며, 별도의 투자 연습 기능 자체를 제거하지는 않음(데이터·계산 호환성 보호).

## 확인
- `npm run typecheck` / 클릭형 HTML 빌드 진행. 실서버 시세 API 응답은 검증 대상 아님.
