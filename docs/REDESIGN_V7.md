# 평행통장 v7 — 생활비에 연결되는 선택·저축·투자

## 제품 정체성
뱅크샐러드 같은 일상 금융 대시보드를 출발점으로, 아직 저축·투자 여유가 없는 20대 초반에게 **돈을 나누고 미래의 결과를 비교하는 연습**을 제공하는 서비스. 실제 금융계좌와 가상 생활비는 절대 합산하지 않는다.

## 주요 화면
1. 홈: 사용 가능 금액을 가장 크게, 저축과 가상 주식 평가금을 명확히 별도 표시. 과거·미래 선택 카드 우선. 학습·기록은 아래.
2. 평행세계: 특정 고민(운동화, 친구 생일, 공연)을 지금 구매 / 더 저렴한 대안 / 미루기 가운데 선택. 모든 선택은 같은 월간 현금 장부에서 검증.
3. 저축·투자: 가상 현금을 저축·주식으로 이동하면 당월 사용 가능 금액 감소. 저축 인출·가상 주식 매도하면 현금 복귀. 주가 가정 변경 시 평가금·총자산 변화. 별도 시장 연습 자금은 기본 동선에서 배제.
4. 금융 학습: 원래의 레슨·중간 퀴즈·오답 피드백 흐름 유지.

## 금액 정의와 제약
- 가상 시작 현금: 800,000원
- 이번 달 예약된 필수지출: 530,000원
- 유지할 최소 완충자금: 150,000원
- 이번 달 사용 가능 = **현금 - 예약 필수지출 - 최소 완충자금** (초기 120,000원)
- 가상 저축 30,000원을 하면 사용 가능은 90,000원, 저축은 30,000원, 총 가상 자산은 동일.
- 가상 ETF 10,000원 매수 시 사용 가능 -10,000원, 주식 평가금 +10,000원. 가격이 -15%면 평가금은 8,500원으로 재평가하며 총자산도 -1,500원.
- 실제 구매 결정은 현금만큼 가능하지만, 최소 완충자금이 줄면 선택 전에 경고한다.
- 가상 저축·매수는 사용 가능 금액을 넘지 못함.
- 이 숫자는 학습 가정일 뿐 실제 잔액이나 주식 수익이 아님.

## 차별점 / 재방문 이유
- 금융 앱처럼 **지금 쓸 수 있는 돈**을 먼저 알려주고, 그 돈을 바꾸는 행동을 바로 제공.
- 구매 전에 같은 생활비로 두 세계의 월말을 비교. 돈을 아끼는 선택을 절대 정답으로 강요하지 않고 구매의 경험 가치도 표현.
- 소비를 미뤄 남긴 돈을 가상 저축·투자와 연결하면 현금은 잠기고 자산은 남는 현상을 이해할 수 있음.
- 이후 사용자 재무 입력과 실제 시뮬레이션으로 확장. 단순한 추측을 은행 데이터라고 표시하지 않음.

## 구현 및 검증 주의
- 이 v7은 기존 Vite React 소스를 수정한 결과. 모델 구조 src/lib/worldWallet.ts에 구현.
- 미리보기 HTML은 코드 실행에 필요한 npm 의존성이 제공되지 않는 환경에서도 테스트 가능하도록 만든 **독립형 인터랙티브 화면 데모**임. 정식 배포물의 완전한 빌드는 아님.
- 기존 서버, 투자 데이터 커넥터, 실제 은행 연동은 검증되지 않았음. 데모 화면에서는 실제 돈이 오가지 않음.
