# 평행통장 v8 — 자산 중심 대시보드 + 평행세계 자산 분기

## 기획 기준
- 타깃: 20대 초반. 예금·적금·주식이 아직 낯설고 여유자금이 적어도 가상으로 자산을 배분해 보고 생활비와의 관계를 체험한다.
- 참고: 뱅크샐러드의 한 화면 안 자산 집계·계좌형 자산 목록·비중 시각화 정보 구조. 다만 UI·텍스트·상표 및 아이콘은 독자 제작이며 기존 서비스의 구체 UI를 복제하지 않는다.
- 차별점: 소비를 안 한 세계, 예금으로 옮긴 세계, 주식으로 산 세계를 같은 자금 원천에서 비교하고 재무 선택의 유동성 차이를 시각화한다.

## 하단 탭
홈 | 평행세계 | 예·적금 | 모의투자 | 금융 학습

## 데이터·금액 회계 원칙
- 가상 총자산 = 현금 + 자유 저축 + 가상 예금 + 가상 적금 + 가상 주식 현재 평가금
- 이번 달 사용 가능 = 현금 − 결제 예정 필수지출 − 생활비 안전선
- 자유 저축/예금/적금 납입 및 가상 주식 매수는 현금에서 각 자산으로 이동한다. *시점의 총자산은 변하지 않는다*.
- 주가가 변하면 가상 주식 평가금과 총자산이 변한다. 매도 전에는 사용 가능 현금에 더하지 않는다.
- 구매를 보류하거나 더 싼 대안을 선택해서 안 쓴 금액은 다른 선택과의 **차이**다. 현금에 이미 남아 있으므로 총자산에 중복 가산하지 않는다.
- 소비를 실제로 가상 장부에 반영한 만큼만 현금/자산이 감소한다.
- `src/lib/worldWallet.ts` 하나에 모든 거래를 적용해 타 화면과 불일치를 방지한다. 이전 localStorage `pb.state.v3`에는 기본 버킷·움직임 배열을 합성해 마이그레이션한다.

## 화면별 기능
- 홈: 자산총계 + 구성막대 + 5가지 자산목록 + 사용 가능 현금 + 평행 리포트 빠른 진입
- 평행세계: 3만 원 기준 현금 보유 / 6개월 예금 / 가격변동 가상 주식의 서로 다른 결과 비교; 소비를 포기해서 생긴 기회와 소비/저축/투자 분기 내역
- 예금·적금: 자유 저축/예금/적금 전용 탭, 금액·기간 선택, 가상 납입 및 현금 반환. 예금 이자와 적금 이자는 단리 세전 가정 표시만 하며 실재 정기 납입 자동 실행과 만기는 구현하지 않았다.
- 모의투자: 수량 선택, 매수/매도, 가상 가격 변동(-15%/+10%), 평가금/현금 분리
- 금융 학습: 기존 커리큘럼, 중간 퀴즈·피드백·실습 화면 유지

## 시뮬레이터 성격 및 한계
- 모든 금액/금리/주가는 가상이다. 금융사 계좌 API 연동이나 투자 주문 기능이 아니다.
- 정기예금의 만기·예금자보호 조건·중도해지 이자·원천징수, 적금 자동이체, 정밀 주식 체결·수수료는 구현되어 있지 않다.
- 초기 체험 데이터는 예시 생활비 80만 원, 결제예정 53만 원, 안전선 15만 원. 사용자가 직접 만든 시나리오도 로컬 저장된다.
- HTML 단독 미리보기는 샘플 데이터와 번들 React를 포함하여 브라우저로 열 수 있다. 라이브 API/주가 브리핑 연동 검증용이 아니다.

## 검증
- Playwright(Chromium) 390px/320px 화면 렌더링, 가로 넘침 및 런타임 오류 확인.
- 예금 1만 원 납입: 사용가능 4만→3만 / 저축자산 6만→7만. 적금 1만: 3만→2만 / 저축 7만→8만.
- 가상 ETF 1주 추가 매수: 사용가능 2만→1만. 가격 -15% 시 주식 평가금 2만→1.7만, 현금 변화 없음.
- 평행세계에서 자산 이동과 소비 차액 확인. 학습 탭 진입 확인.
- 단독 월렛 회계 테스트 통과. 현재 환경에서는 일반 `npm install` 기반 전체 빌드/서버 연동까지 검증하지 못함.
