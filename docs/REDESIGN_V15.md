# v15 · 가독성 전면 개편 + 평행세계 비주얼

중간발표 피드백(가독성) 반영. 토스·뱅크샐러드식 정보 위계로 5개 탭과 소비 비교 화면을 다시 짰다.

## 원칙
1. 한 화면에서 가장 중요한 숫자는 하나 — 크게(34~40px), 굵게.
2. 카드 안에 카드를 넣지 않는다. 구분은 여백과 얇은 선.
3. 본문 15px 이상, 보조 13px 이상. 11px 회색 글씨 제거.
4. 파랑(#3182F6) 하나 + 회색 9단계. 의미 있을 때만 다른 색.
5. 평행세계는 앱의 정체성 → 유일한 어두운 '우주' 카드로 구분.

## 바뀐 것
| 화면 | 변경 |
|---|---|
| 홈 | 첫 카드를 '이번 달 쓸 수 있는 돈'으로. 결제 예정·안전선·자유 금액을 한 줄 막대로 보여주고 바로 '두 세계 비교' 버튼. 평행세계 티저 카드(어두운 포털), 자산·가계부 단순화 |
| 평행세계 | 단순 선 그래프 → `ParallelUniverse` (별이 있는 우주, 빛나는 '내 세계' 궤적, 유령 점선 '정가 세계', 두 세계 사이 빛 리본, 갈림길 노드, 차이 괄호 라벨, 궤적을 따라 흐르는 혜성, 드래그로 날짜 이동) |
| 소비 비교 | A/B 회색 박스 → 한 점에서 두 갈래로 갈라지는 어두운 분기 카드. 선택지는 라디오형 행 |
| 예·적금 | 큰 금액 입력(콤마 표시), 빠른 금액 칩, 요약 표, '두 갈래 길' 비교 |
| 모의투자 | 시장 상태·코스피 칩, 총자산 위계, 검색·관심 칩, 종목 행 정리 |
| 금융 학습 | 진행률 링, 오늘의 학습 카드, 진행 막대가 있는 주제 그리드 |
| 공통 | 하단 메뉴 아이콘 중복(홈·예적금 모두 지갑) 해결, 기존 하위 화면 토큰을 새 팔레트로 연결 |

## 파일
- `src/ux-v15.css` — 새 디자인 시스템(마지막에 로드)
- `src/components/ParallelUniverse.tsx` — 평행세계 비주얼(`ParallelUniverse`, `ParallelMini`)
- `src/screens/V8Finance.tsx`, `WorldTimeline.tsx`, `Learn.tsx`, `ParallelLab.tsx`(비교 카드) 재작성
- 계산 로직(`src/lib`, `shared`)은 건드리지 않음. 테스트 113개 통과.

움직임은 `prefers-reduced-motion`과 앱 내 '움직임 줄이기' 설정을 모두 따른다.
