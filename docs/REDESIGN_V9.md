# 평행통장 v9 — 평행세계 타임라인 / 모의투자 화면 복구

## 변경 범위

- 홈·예금/적금·학습은 v8 그대로 유지한다.
- **평행세계 첫 화면**은 `날짜별 두 세계 그래프 → 빠른 소비 선택 입력 → 과거 선택 기록` 순서로 재구성했다.
- 모의투자는 v8의 `V8Invest`를 사용하지 않고, **직전 v7의 `WorldInvestment` 컴포넌트로 복원**한다. 월 사용 가능 현금과 보유 가상자산 장부는 v8의 `worldWallet`을 공유한다.
- 기존 `ParallelLab`은 상세 비교 진입 경로를 위해 삭제하지 않는다.

## 그래프의 해석

- 파란 실선: 현재까지 앱에 기록한 실제 *가상 선택*에 따른 사용 가능 현금
- 보라 실선: 기록한 모든 고민 소비를 원래 가격으로 구매했다고 가정했을 때 사용 가능 현금
- 공통: 저축·예금·적금·모의 주식으로 현금을 옮긴 이벤트는 양쪽 세계의 사용 가능 현금에서 동일하게 제외한다. 현금 → 자산 전환은 총자산의 소멸이 아니다.
- 지표: `현금 - 530,000원(고정지출 가정) - 150,000원(안전선)`; **총자산 그래프가 아니다.**
- 이벤트가 없는 날짜는 마지막 잔액을 유지한다. 없는 지출을 만들어 매일 흔들리는 그래프를 보여주지 않는다.
- 차이는 두 세계의 현금 차이이며 추가 자산으로 더하지 않는다.
- 시계열은 KST 기준 7·30·90일 선택, 날짜별 터치/클릭 상세 조회를 지원한다.
- 기존 저장 데이터의 과거 장부에 빠진 항목은 현재 잔액에 맞추기 위해 상수 보정한다. 과거 은행 잔고를 복원했다는 주장이 아니다.

## 입력

- 물건/상황, 원래 가격, 선택(구매/보류/대안 가격)을 받는다.
- 선택을 저장하면 `worldWallet`에 기록되고, 그래프·홈 자산·예적금·모의투자에 동시에 반영된다.
- 가상 종목 주가 변동은 현금흐름 그래프에 반영하지 않고 모의 투자 평가금에만 반영된다.

## 검증 사항

- 반응형: 320/390/480px 너비에서 가로 넘침 없는지 확인
- 일별 그래프 변화, 소비 입력 이후 두 세계 차이 업데이트, 거래 기록 필터링
- 모의투자 진입 시 v7 화면 노출과 가상 생활비 장부 연결
- 독립형 HTML은 예시 데이터로 동작하며 서버 연동은 별도 검증 필요
