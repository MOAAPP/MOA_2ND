# 평행통장 UX 개편 · 2026-10-20

## 이번 개편에서 바꾼 사용자 동선

원래: 홈 → 갈림길/미래/배움 → 배움 내 모의투자 → (투자), 소비 입력 3단계 → 복잡한 추이 그래프

개편: **홈 · 소비 비교 · 모의투자 · 금융 가이드** (4개 독립 탭)

- **홈**: 현재 잔고와 월말 예상 잔고를 먼저 확인 → `사기 전 비교` 또는 `목표` 이동. 상세 날짜 그래프는 펼침 패널로 이동.
- **소비 비교**: 가장 먼저 `새 소비 비교하기` 진입 → `품목(선택) + 금액(필수) + 날짜(선택)` → `지금 구매 / 안 사기·미루기·저렴한 대안`의 월말 예상 잔고 → **얼마나 차이나는지** → 선택 기록. 심화 위험·그래프는 별도 펼침 패널.
- **모의투자**: 학습 탭의 하위 메뉴에서 독립 탭으로 이동. 기존 모의 자산·종목 검색·매수·매도·관심 목록·거래 내역 유지.
- **금융 가이드**: 긴 지그재그 코스 제거. 6개 주제별 카드·간단한 이어 읽기·선택형 퀴즈·모의투자 이동으로 변경. 기존 24개 강의 콘텐츠와 선택형 레벨테스트는 유지하며, 주제별 글은 잠금 없이 읽고 읽음 기록을 남길 수 있습니다.
- **목표**: 별도 하단 탭 대신 홈의 도달 가능한 목표 카드에서 이동. 목표 생성·진행률·목표 시뮬레이션 유지.

## 변경된 주요 파일

- `src/screens/Learn.tsx` · `src/screens/GuideArticle.tsx`: 가이드 카드·자유 읽기·읽음 기록 및 독립 모의투자
- `src/screens/Future.tsx`, `src/screens/Portfolio.tsx`: 메뉴 이동 및 뒤로 가기
- `src/ux-refresh.css`: 새 시각 디자인 및 모바일 반응형 스타일

## 미리보기

`평행통장_클릭_미리보기.html`을 크롬·사파리 등에서 열어보세요. 별도의 패키지 설치 없이 **예시 데이터가 미리 설정된 UI**를 클릭할 수 있습니다. 원본 앱의 실제 React 컴포넌트를 변환한 UI 미리보기이며, 가상의 데이터입니다. API 서버가 없으므로 실시간 시세, Discord 발송, 사진 OCR, 서버 의존 카드는 정상 작동하지 않을 수 있습니다. 이 파일은 배포 가능한 전체 서비스가 아닙니다.

실제 서비스 실행은 프로젝트 폴더에서 `npm install` → `.env.example`로 `.env` 설정 → `npm run dev` 입니다. API 서버도 함께 실행됩니다. (개인 키가 들어 있는 `.env`는 배포 파일에서 제외했습니다.)

## 검증 범위

- TypeScript: `npm run typecheck` 통과.
- React 서버 측 HTML 렌더링 확인: 홈, 모의투자, 금융 가이드, 소비 입력, 소비 결과, 목표.
- 오프라인 HTML 내 스크립트 4개: `node --check` 파싱 확인.
- 제한 사항: 이 환경에 포함된 Mac 전용 Rollup/Esbuild 바이너리와 네트워크 제약으로 `vite build`/브라우저 E2E 시각 검증은 실행하지 못함. 최종 브라우저 기기 테스트와 API 연동 테스트 필요.
