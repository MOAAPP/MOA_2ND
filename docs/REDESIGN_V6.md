# 평행통장 v6 · 핵심 가치 복원과 0원 체험 UX

## 누구에게 필요한가

20대 초반 대학생·사회초년생, 특히 **실제 저축·투자 여유가 아직 없는 이용자**가 타깃이다. 소비를 기록하거나 종목 수익률을 보는 것보다 "같은 생활비에서 다른 소비를 택하면 이달과 다음 달이 얼마나 달라질까"라는 질문에 답한다. 사용자에게 금융 공부를 먼저 요구하지 않는다.

## 사용자가 20초 안에 이해해야 할 문장

> 돈이 없어도 연습할 수 있어요. 같은 생활비, 다른 선택. 이번 달의 나도, 앞으로의 나도 달라집니다.

앱의 체험 가치는 예·적금 가입이나 실전 투자 권유가 아니다. 사용자가 소비 직전에 **월세와 반드시 지켜둘 돈을 침해하는지**, 미루거나 대안으로 바꾸면 **이번 달 여유와 다음 달 부담이 어떻게 달라지는지** 직접 확인할 수 있다는 것이다.

## 본래 기획서에서 되살린 원칙

- 정규 MVP의 코어는 **사기 전 확인 + 날짜별 현금흐름 + 두 세계 비교**이다.
- 평행세계가 "아무것도 사지 않은 이상적인 나"만 보여주면 비현실적이다. 사용자가 선택한 소비만 비교하고 대체비용을 인정한다.
- **월세·필수지출·최소 유동성**을 먼저 보호한다. 큰 수익률 대신 월말 안전 여유금과 일정상 부족 발생 여부를 보여준다.
- “안 사라”, “나쁜 소비” 등 죄책감을 주는 문구 대신 선택의 차이와 경험의 가치를 함께 제시한다.
- 과거 잔고를 실제로 복원했다고 주장하지 않는다. 과거 대안 비용은 **가상 차이**임을 표시한다.
- 모의투자의 수익 구간은 가정과 기간을 함께 표시하고 실시간 시장 시세·개인 추천과 분리한다.

## 사용자 흐름

```text
온보딩
  ├─ [0원으로 체험하기] → 바로 평행세계 체험 (계좌·잔고 입력 없음)
  │     ├─ 미래: 스니커즈·배달·카페 소비의 현재/대안/보류 → 월말 잔고
  │     ├─ 과거: 지난 배달을 집밥으로 바꿨다면 → 오늘까지의 가상 금액 차이
  │     └─ 돈의 다음 세계: 필수지출 제외 → 여유금 분배 → 수익률 가정 → 1분 퀴즈
  │           ├─ 짧은 금융 학습 (기존 중간 퀴즈·피드백 기능 유지)
  │           └─ 독립 모의투자 (기존 주문/보유종목 기능 유지)
  └─ [내 생활비로 시작] → 기존 재무 정보 온보딩 → 개인 현금흐름 비교

홈 → 0원 가상 체험을 상단에 고정 → 내 소비 입력은 두 번째 구역
평행세계 탭 → 기존 과거/미래 실데이터 전환 유지
```

## 가상 시나리오 계산 예시

가상 시작 생활비 800,000원, 월말까지 필수지출 530,000원, 항상 지켜둘 돈 150,000원.

- 지출 전 월말 잔고: 800,000 − 530,000 = **270,000원**
- 운동화 129,000원 오늘 구매: **141,000원**. 지켜둘 금액보다 9,000원 부족
- 이번 달 구매를 미루면 **270,000원**. 다음 달 129,000원 부담 가능성을 표시
- 39,000원 대체 상품: **231,000원**. 오늘 구매 세계보다 90,000원 남음
- 가상 투자에 쓸 여유금 = 270,000 − 150,000 = **120,000원**. 0~100% 배분 조절
- 투자 결과는 실제 시장 예측이 아님: 1년 뒤 가상 원금의 90~110% 시나리오 범위로만 설명

## 팀원 ML 작업을 사용자 UX와 분리

`src/lib/ml/*`, 기존 연동 계약, 서버 소스는 삭제하지 않았다. 사용자 화면에서 “팀원 ML 확장용 설계”, “LightGBM 교체” 등의 개발 내부 문구는 제거했다. 사용자에게는 실제로 확인 가능한 **소비가 몰리는 날 / 예측한 생활비 / 다른 선택의 월말** 정도만 노출한다. 모델이나 데이터가 충분하지 않으면 명확히 추정치로 표기한다.

## 차별점과 재방문 이유

가계부는 과거 기록, 투자 앱은 실전 시세, 절약 챌린지는 못 쓴 돈 자체를 강조한다. 평행통장은 **결정을 하기 직전**, 내 남은 필수 생활비와 미래 날짜를 반영해 세 가지 현실적인 선택을 검증하고, 원하면 **그 선택의 분기점을 다음 달에 다시 회고**하도록 연결한다. 체험 모드의 예시는 첫 진입 장벽을 낮추고, 내 소비를 통한 실제 계산이 재방문 가치를 만든다.

## 구현 여부

- 구현: 통합된 가상 체험 컴포넌트, 세 가지 반복 소비 예시, 미래 선택 즉시 비교, 과거 가상 회고, 필수지출 보호 가상 투자 배분, 1분 퀴즈, 홈 진입, 온보딩에서 즉시 실행, 개발자용 ML 설명 제거.
- 기존 코드 재사용: 현금흐름 계산, 과거 기록, 실제 소비 비교, 금융 학습 레슨과 중간 퀴즈, 투자 화면.
- 추가로 필요한 제품 작업: 시나리오 콘텐츠 서버 관리, 기간별 선택 경험의 개인화, 실제 고객 테스트, 접근성 실사용 검증. 아직 연동·배포가 검증된 기능으로 표현하지 않는다.
