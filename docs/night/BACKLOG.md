# 모아 v16 야간 백로그 (세션마다 최대 2개, 위에서부터)

## 제품 방향
- 핵심: 소비 선택의 미래 비용 시각화(교수님 피드백 "주식으로 3만 원 벌 거면 왜 쓰냐"). 투자는 참은 돈의 목적지 중 하나 + 학습.
- 흐름: 사고 싶은 것 기록(결제 전) → 참기/사기 → 참은 돈은 모아 가상계좌로 → 예금/적금/투자 선택 → "샀던 세계 vs 참은 세계" 비교. 가계부(결제 후)도 같이.
- 지현 불만: 유저플로우가 별로, 예적금·투자가 장난감 같음. 토스·뱅크샐러드 수준 목표. 원 단위 정수, 조건·약관 요약·세금·수수료.
- 논문 확장: 로직 문서화 + 테스트 + 연구용 로깅. KIS API(계좌 필요) 쓰지 않기. ML 인터페이스(src/lib/ml) 유지·확장.
- 한국어 문구는 자연스럽고 짧게(토스 말투). 모바일 375px 우선, 터치 44px.
