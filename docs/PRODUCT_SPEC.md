# 모아(평행통장) v16 제품 기획서

> 이후 모든 개발의 기준 문서. 화면·로직을 바꿀 때 이 문서를 먼저 고친다.

> **2026-10-29 기획서로 방향이 바뀜.** 핵심 기능은 "7~14일 안 필수결제일의 결제계좌 부족 탐지"이며, 계산 규칙의 기준은 [docs/ENGINE.md](ENGINE.md)다. 이 문서와 다르면 ENGINE.md를 따른다.

## 1. 한 줄 정의
사기 전에 **"이 돈을 안 쓰면 미래가 어떻게 달라지는지"** 보여주고, 참은 돈을 실제 금융상품처럼 굴려보게 하는 20대용 소비 의사결정 서비스.

### 교수님 피드백 반영
- "주식으로 3만 원 벌 거면 왜 쓰냐" → 투자 수익이 주인공이 아니다.
- 주인공은 **소비 선택의 미래 비용**(다음 달 생활비, 결제일 잔고, 목표 달성일이 어떻게 바뀌는지).
- 예금·적금·투자는 "참은 돈이 어디로 갈 수 있는지" 보여주는 **목적지**이자 금융 학습 도구.

## 2. 핵심 루프
```
사고 싶은 게 생김
  → [결정] 금액 입력 → 미래 비용 미리보기(이번 달 / 결제일 / 1년 뒤)
  → 참기 · 대안 · 미루기 · 사기
  → 참은 돈은 '모아 통장'으로 자동 이동
  → [모으기] 예금 · 적금 · 투자 중 선택해서 굴리기
  → [평행세계] "샀던 세계 vs 참은 세계" 차이가 시간에 따라 벌어짐
  → 다음 결정 때 더 쉽게 참음 (재방문)
```
결제 후 기록(가계부)은 같은 루프의 입력이다. 이미 쓴 돈이 다음 결정의 "쓸 수 있는 돈"을 줄인다.

## 3. 정보 구조(IA)
하단 탭 5개(v18). 가계부가 서비스의 기본 입력이라 탭으로 올렸다.

| 탭 | 역할 | 첫 화면의 단 하나의 숫자 |
|---|---|---|
| 홈 | AI 브리핑 + 오늘 내 돈 상태 + 결정 시작점 | 이번 달 쓸 수 있는 돈 |
| 가계부 | 결제 후 기록(직접 쓰기·카드 문자 붙여넣기), 내역·달력·분석, AI 요약 | 이번 달 지출 |
| 평행세계 | 선택의 누적 효과, 리포트 | 다르게 선택해서 지킨 돈 |
| 모으기 | 가상 예금·적금(상품 가입·관리) | 모은 돈(원금+이자) |
| 투자 | 머리 탭으로 [모의투자 · 금융 학습] | 총 평가금액 |

AI 기능은 docs/AI.md. 설정에는 사용자에게 필요한 것만 둔다(생활비 정보, 레벨 테스트, 움직임 줄이기, 소개, 알림, 데이터 지우기).

## 4. 유저플로우

### F1. 첫 실행
인트로(3장) → "예시로 둘러보기" 또는 "내 돈으로 시작" → 기본 설정(잔고·월급일·고정지출·목표) → 홈.
- 설정은 4단계 이하, 단계마다 건너뛰기 가능. 건너뛴 값은 홈에서 "아직 안 정했어요" 행으로 다시 유도.

### F2. 결정(핵심)
홈 "사기 전에 두 세계 비교하기" → 품목·금액 → 미래 비용 미리보기 → 선택 → 결과 화면.
- 미리보기는 숫자 3개만: **이번 달 쓸 수 있는 돈 변화 / 다음 결제일 잔고 / 1년 뒤 차이(예금 기준)**.
- 참기·대안 선택 시 "모아 통장으로 n원 옮겼어요" + "바로 굴리기" 버튼(→ F4).
- 구현(v16 N7, `src/screens/Choose.tsx`, 계산 `src/lib/futureCost.ts`):
  - 빈도 선택: 이번 한 번 / 매주 / 매일. 이번 달 비용 = 오늘~말일 남은 횟수 × 가격(매주는 ceil(남은 일수/7)).
  - ① 이번 달 쓸 수 있는 돈 = 현금 − 이번 달 비용 − 고정지출 − 지켜둘 생활비 ② 다음 결제일(다음 달 1일) 잔고 = 현금 − 이번 달 비용 − 고정지출 ③ 1년 뒤 차이 = 아낀 돈(1회 금액 × 연 횟수 52/365)을 12개월 상품에 넣은 세후 수령액. 한 번이면 정기예금, 반복이면 매달 (연간 금액/12)을 넣는 적금 중 세후 이자가 가장 큰 상품. 우대금리는 지금 달성한 조건만.
  - '모아 통장' = 자유 저축 칸(이자 없음, 언제든 꺼냄). 이번 달 쓸 수 있는 돈이 모자라면 옮기지 않고 현금에 둔다.
  - 선택 기본값은 없음(연구에서 기본값 효과를 피하려고).

### F3. 가계부
홈 가계부 카드 → 월 달력/리스트 → + 버튼(바텀시트, 숫자패드) → 카테고리 자동 추천(ML 분류) → 저장.

### F4. 모으기(예금·적금)
모으기 탭 → 내 계좌 목록(없으면 추천 상품) → 상품 비교(최고금리·기간·조건 정렬) → 상품 상세 → 가입(금액·기간 → 약관 요약 확인 → 최종 확인) → 가입 완료 → 계좌 상세.
- 계좌 상세: 만기 D-day, 지금까지 이자, 만기 예상 수령액(세전·세후), 납입 회차(적금), 우대조건 달성 현황, 중도해지 미리보기.
- 우대금리 조건은 **앱 안의 행동**으로 정한다(예: 이번 달 참기 3번, 가계부 7일 기록). → 연구용 개입 변수가 된다.

### F5. 투자
투자 탭 → 종목 → 주문 바텀시트(금액/수량 전환, 숫자패드) → 체결 → 보유·수익률. 학습 레슨과 연결.

### F6. 평행세계 리포트
평행세계 탭 → 두 세계 궤적 → 선택별 기여도 → 월별 비교 → 공유 카드.

## 5. 도메인 모델

### 5.1 돈의 위치
| 위치 | 설명 |
|---|---|
| 현금(가상 계좌) | `worldWallet.cash`. 모든 이동의 출발·도착지 |
| 자유 저축 | 언제든 꺼내는 칸 |
| 예금 계약 | `bank.contracts[kind='deposit']` |
| 적금 계약 | `bank.contracts[kind='installment']` |
| 투자 | ETF 보유분 |

`worldWallet.deposit`, `worldWallet.installment`는 **활성 계약 원금 합계의 캐시**다. 계약이 바뀔 때마다 다시 계산한다(홈·평행세계가 이 값을 읽음).

### 5.2 상품(Product)
가상 은행 4곳, 상품 6개 내외. 실제 금융사 이름은 쓰지 않는다.
```
Product {
  id, bank, name, kind: 'deposit' | 'installment',
  installmentType?: 'fixed' | 'free',      // 정액적립식 / 자유적립식
  compounding: 'simple' | 'monthly',
  rates: { months, baseRate }[],           // 기간별 기본금리(연 %)
  preferential: { id, label, bonus, rule }[],
  maxPreferential,                          // 우대금리 합계 상한
  minAmount, maxAmount, (적금) maxMonthly,
  earlyRates: { underMonths, ratio | fixed }[],  // 중도해지 이율
  tags, summary, terms[]                    // 약관 요약 3~5줄
}
```

### 5.3 계약(Contract)
```
Contract {
  id, productId, kind, openedOn, maturityOn, termMonths,
  baseRate, preferentialIds[],              // 가입 시 확정된 기본금리, 달성한 우대조건
  payments: { on, amount, auto }[],         // 예금은 1건, 적금은 회차별
  monthlyAmount?, autoDay?,                 // 정액적립식 자동이체
  status: 'active' | 'matured' | 'closed',
  closedOn?, payout?: { principal, interest, tax, net, reason }
}
```

### 5.4 시간
- 모든 날짜는 KST 'YYYY-MM-DD'.
- 데모·발표용 **시간 이동**: `bank.clockOffsetDays`를 더한 날짜를 앱의 오늘로 쓴다. 이동 시 그 사이의 자동이체·만기를 순서대로 처리한다.

## 6. 계산 규칙 (원 단위 정수)

### 6.1 공통
- 금리는 연 %, 계산 시 소수로 변환.
- 이자는 **원 미만 절사**.
- 이자소득세 15.4% = 소득세 14% + 지방소득세 1.4%. 각각 **10원 미만 절사**.
  `tax = floor(i×0.14/10)×10 + floor(i×0.014/10)×10`
- 적용 금리 = 기본금리 + min(달성 우대금리 합, 상한).

### 6.2 정기예금
- 단리: `이자 = floor(원금 × r × 일수 / 365)`
- 월복리: `이자 = floor(원금 × ((1 + r/12)^개월 − 1))`

### 6.3 정액적립식 적금(단리)
회차 k(1..n)의 예치 개월 = n − k + 1.
`이자 = floor(월납입액 × r/12 × n(n+1)/2)`
미납 회차는 이자 0, 지연 납입은 지연 일수만큼 예치 기간이 줄어든 것으로 본다(입금일 기준 일할).

### 6.4 자유적립식 적금
`이자 = Σ floor(입금액_i × r × (만기일 − 입금일_i) / 365)`

### 6.5 중도해지
- 해지일까지 경과 기간에 따라 **기본금리 × 비율**(우대금리 없음)로 일할 계산.
- 기본 비율표: 1개월 미만 0.1%(고정), 3개월 미만 10%, 6개월 미만 30%, 9개월 미만 50%, 그 이상 60%.

### 6.6 만기
- 만기일이 되면 자동으로 원금+세후이자를 현금으로 돌려준다(기본). 계약은 `matured`.
- 만기 후 이자는 주지 않는다(단순화, 화면에 명시).

## 7. 화면 문구 원칙
- 한 화면 한 메시지. 숫자는 크게, 설명은 한 줄.
- "~했어요 / ~할 수 있어요" 말투. 금지: "~하십시오", 느낌표 남발, 영어 섞기.
- 가상 상품임을 상품 상세·가입 확인에 반드시 표시.

## 8. 엣지케이스
| 상황 | 처리 |
|---|---|
| 이번 달 쓸 수 있는 돈보다 많이 가입 | 가입 버튼 비활성 + 부족 금액 표시 |
| 자동이체일에 현금 부족 | 그 회차 미납 처리, 계좌 상세에 빨간 점 + "다음 날 다시 시도하지 않음" 안내 |
| 31일 자동이체 | 그 달 말일 |
| 시간 이동으로 여러 회차 경과 | 날짜 순서대로 하나씩 처리 |
| 예전 버전의 예금·적금 잔액 | '기존 가상 예금/적금' 계약 1건으로 옮김(연 3%, 오늘 가입, 12개월) |
| 해지 확인 | 반드시 확인 시트(받는 금액·잃는 이자 비교) |

## 9. 연구(논문) 연결
- 독립변수 후보: 미래 비용 미리보기 노출 여부, 우대금리 조건(행동 연동) 유무.
- 종속변수: 참기 비율, 참은 금액, 재방문 간격, 적금 유지율(중도해지율), 납입 성실도.
- 모든 계산은 순수 함수 + 단위 테스트(`tests/bank*.test.ts`)로 재현 가능하게 둔다.
- 이벤트 로깅 스키마·실험 조건·분석 계획은 `docs/RESEARCH.md`. 설정 → 연구 참여에서 동의한 사람만 기록되고, B조건은 결정 화면의 미래 비용 숫자를 숨긴다.
