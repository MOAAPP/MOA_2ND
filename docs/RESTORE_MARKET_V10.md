# v10 · 실제 시세 연동 모의투자 화면 복구 (2026-10-20)

## 버그 원인
- v9의 하단 `모의투자` 탭은 `WorldInvestment`를 표시했습니다. 이 화면은 학습용 고정 가격 ETF를 다루어 실제 종목 목록·시세 API가 숨겨졌습니다.
- 원본 React 화면 `Practice`와 `StockDetail` 및 REST/SSE/KIS 시세 API 서버 코드는 이미 프로젝트에 존재했습니다.

## 이번 복구
- 하단 `모의투자` → 기존 `Practice`로 원상복구: 종목 검색·관심·가격/기준시각/출처·매수/매도·보유내역 및 카드뉴스 경로 유지.
- 홈의 `생활비 연동 가상 ETF` 항목은 별도 `budgetInvest` 화면으로 접근: 기존 v9 가상 생활비 원장과 저축/투자 평가금 반영 기능을 유지.
- API 기반 모의투자와 생활비 기반 ETF 연습은 **별개의 자금장부**라는 점을 UI에 표시합니다. API 기반 기존 모의투자는 1,000만 원 독립 연습자금으로, 홈 총가상자산에 합산되지 않습니다.
- `Practice` 내 버튼으로 생활비 ETF로 바로 이동할 수 있습니다.

## 시세 API
- 서버: `server/lib/quotes.ts`, `server/lib/providers/kis.ts`, `kisRealtime.ts`; `/api/quotes`, `/api/stream`.
- 국내 종목과 ETF 시세 제공처는 설정과 시장 상황에 따라 KIS/네이버/Yahoo 등이며, **실시간 체결이 언제나 보장되는 것은 아닙니다**.
- 서버 `.env`의 `KIS_APP_KEY`, `KIS_APP_SECRET`가 필요하며 실서버 연결/수신 성공 여부는 별도 검증이 필요합니다.

## 수동 확인 순서
1. `npm ci && npm run dev` 후 온보딩 진행.
2. 모의투자 탭 → 종목 이름 검색 → 종목 상세 → 시세 제공처와 갱신시각 표시 확인.
3. 시장 상태가 허용되면 모의 매수/매도·주문 내역 확인.
4. 모의투자 상단 `생활비 연동` → 별도 연습용 ETF에서 매수 후 홈의 생활비 변동 확인.
5. 예·적금/평행세계 리포트/금융학습 회귀 테스트.

## 주의
- 실제 주식 주문과 금융기관 자산을 다루지 않습니다.
- `public/vendor` 등을 이용한 오프라인 단일 HTML 미리보기에서는 외부 시세 API가 정상 동작하지 않을 수 있습니다. 실시간 테스트는 API 서버와 함께 실행해야 합니다.
- Webhook/API 비밀키는 반드시 서버 비공개 환경변수에 입력하고 ZIP에 포함하면 안 됩니다.
