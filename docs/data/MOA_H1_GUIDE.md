# MOA 공통 가상 데이터 — 1차 46일

기간: **2026-09-11 ~ 2026-10-26 (양끝 포함 46일)**. 다음 반쪽은 2026-10-27 ~ 2026-12-11 (46일). 

이 파일들은 모든 사람이 가상으로 생성된 **10개 사용자 시나리오**입니다. 실제 은행 거래나 설문 대상자가 아닙니다. 현재 프론트 데모 기본 프로필은 S01입니다.

## 팀원 바로 사용
- 원본: `src/data/moa-half1.json` 또는 배포 URL의 `/data/moa-half1.json`
- 편리한 CSV: `public/data/moa-half1-profiles.csv`, `...-transactions.csv`, `...-daily.csv`, `...-choices.csv`, `...-investments.csv`
- 재현: `node scripts/data/build-half1.mjs` (고정 난수 seed 20261104)

## 시나리오
S01 보통 대학생, S02 알바비 지연, S03 주말 지출 집중, S04 거래 누락, S05 고정비 부담, S06 신용카드, S07 시험기간 지출 급증, S08 절약, S09 불규칙 소득, S10 월말 부족 위험.

## 스키마 및 주의
- `transactions`: 가상 거래, `logged=false`는 앱에 입력되지 않은 거래. `credit` 카드 구매는 즉시 결제계좌에서 출금하지 않음.
- `daily`: 사용자 × 날짜 460행. `true_variable_spend`는 **합성 데이터 생성기만 알고 있는 정답**이며 AI 입력 변수로 사용 금지. `observed_variable_spend`는 기록된 거래만의 합, 누락이 있으면 `model_label=null`로 정답 제외. 미기록일은 0원으로 가정하지 않음.
- `split`: train(30일), validation(8일), test(8일). 모델 개발 검증용이며 **표본이 적어 우수한 ML 성능을 주장할 수 없음**. 시간에 따른 누수 금지, 같은 사용자의 미래 시점 특징을 과거 예측에 넣지 않기.
- `choices`: 구매/보류/대체 선택 시뮬레이션. 소비 거래에 다시 합산하면 중복 집계됨.
- `investments`: **가상 투자** 매수/매도 기록. 평가액은 총자산에만 포함하고 현금은 매도 체결 이후 사용 가능. 결제계좌 거래와 이중 반영하지 않기.
- DB 필요 없음. 개인 데이터가 아니며 시연용. 실제 모델 검증 결과와 반드시 구분.
