# S01 메인 시연 사용자 — 연결형 합성 금융 시나리오

> **100% 합성 데이터입니다.** 실제 계좌·실제 구매·실제 검증·AI 모델 정확도가 아닙니다.
> 2026-11-04 기준의 가상 관측 기록만 프론트에 노출하며, 11/05~12/11은 미래 시나리오 테스트 데이터입니다.

## 시연 목표

평행통장(MOA)의 핵심 가치를 **한 사람의 연결된 흐름**으로 설명합니다.

**알바비·과외비 → 반복 결제 → 일상 지출·돌발 지출 → 결제일 위험 → 소비 보류·대안 비교 → 가상 ETF 보유** 순서로 소개하세요.

이 시연 데이터는 다른 19명(S02~S20)과 독립적으로 생성하고, 기존 19명 데이터는 한 줄도 변경하지 않습니다.

## 화면을 보여주는 순서 (약 3~5분)

1. **온보딩 → 예시로 둘러보기**: S01 시연 데이터 자동 로드. 개인의 실제 기록은 덮어쓰지 않음
2. **홈 / 결제일 위험**: 11/04 기준 34,700원 잔액과 5·8·14·15일 결제일을 확인. 카드 347,000원은 10월 사용의 **11/14 출금 예정**이며, 10월 소비 시점에는 계좌에서 차감되지 않음
3. **가계부**: 9~11월 생활비·고정비·일회성 큰 지출을 함께 확인. 10/23·11/02의 일부 미기록 건은 실제 가계부에 보이지 않고 ML 학습 정답에서 제외
4. **평행세계**: 이어폰을 사는 선택, 야식 보류, 버스를 택하는 대안을 비교. 선택 기록은 가상 지갑의 의사결정이고 같은 비용을 계좌에서 **추가 중복 차감하지 않음**
5. **가상 투자**: TIGER 미국S&P500(360750)과 KODEX 200(069500)의 체결·보유 수량을 확인. 아직 팔지 않은 ETF는 소비 가능한 결제계좌 현금이 아님
6. **AI 설명**: 날짜별 정답이 확인된 합성 구간만 요일별 기준선 학습에 사용하며, 미래 정답·기록 누락을 학습 데이터로 넣지 않음. 이는 **모델의 실제 정확도 실증이 아님**

## 기술적으로 특히 강조할 것

- **S01만 증강**: S02~S20의 프로필·거래·일별·선택·ETF CSV 행은 확장 전과 완전히 동일
- **결제계좌 원장**: 날짜별 잔액 = 전날 잔액 + 실제 입금 − 체크·이체 출금 − 카드대금 출금 + 비상 이체. 신용 구매와 카드 청구 중복 출금 없음
- **시뮬레이션 분리**: 11/04까지 기록한 거래만 프론트에 포함. 이후 가상의 소비·급여·ETF 체결은 공용 데이터셋 테스트에만 포함
- **정보 누수 방지**: 기록 누락과 미래 날짜의 `model_label`은 항상 `null`; `true_variable_spend`는 합성 데이터 생성기와 평가용으로만 사용
- **프론트의 기록 상태**: 시연용 합성 데이터에서만 확인된 날짜를 자동으로 표시. 실제 사용자는 매일 '다 기록했어요'를 누르지 않음
- **시연 준비**: 기존 로컬 사용자 데이터가 있으면 예시로 둘러보기에서 덮어쓰지 않으므로, **새 브라우저 프로필 또는 새 시크릿 창**에서 확인
- **DB 없음**: `src/data/moa-demo-s01.json`을 번들에 포함하여 프론트에서 동작. 공통 `public/data/moa-92days.json`/CSV를 Python·백엔드 팀에 공유

## 주의

현재 S01은 **시연 가능한 복잡한 테스트 케이스**이지 실제 은행 연동, 자동 거래 동기화, 20명 실사용자, ML 정확도 검증 결과를 의미하지 않습니다. 사용자에게 화면을 보여줄 때도 이 구분을 유지하세요.
