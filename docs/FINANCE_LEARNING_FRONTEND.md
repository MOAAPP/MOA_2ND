# AI 금융 학습 프론트 통합

공식 main 251a592를 기준으로 금융 엔진·평행세계·Agent 팀원 연결을 유지하고 추가했다. main 머지 및 공식 배포 설정 변경은 수행하지 않는다.

## 구현
- 기존 ZIP 추출 → 팀별 패치 → 금융 학습 패치 → API 번들 → 프론트 빌드 순서를 사용한다. ZIP이나 전체 화면을 교체하지 않는다.
- 홈·학습 화면에서 관심사, 최근 오답 우선 복습, 힌트, 답안 저장, 정답/오답별 해설, 학습 이력을 FastAPI와 연결한다.
- 카드뉴스 화면에서 이미지 4장·출처·AI 모델/규칙 대체 여부·연결 퀴즈를 표시한다. 새 모의 매수 체결을 감지하고 동의 설정에 따라 생성/전송한다.
- 기존 기기 식별값과 Discord 목적지/발송 문구를 유지한다. 실제 시세와 가상 시세를 구분한다.
- Node 카드 서버는 기존 렌더러를 재사용한다. 영구 상태, lease, 중복·실패 처리 및 내부 정기 실행 경로를 연결한다.

## 설정 및 제한
- 개인 키, test 도메인, Vercel 프로젝트 설정은 포함하지 않는다. 기존 FACTCHAT_API_KEY/FACTCHAT_MODEL 및 사진·Discord 키는 각자 서버 환경변수로 설정한다.
- FastAPI 연결은 기존 MOA_FASTAPI_ORIGIN과 MOA_PROXY_SHARED_KEY를 재사용하고 선택적으로 MOA_FINANCE_API_BASE를 사용할 수 있다. 영구 카드 상태를 사용할 때 FE/BE의 MOA_INTERNAL_SECRET이 일치해야 한다.
- 현재 공식 backend의 학습 기능은 S01–S20 합성 사용자 기반이다. 실사용자 인증·개인 데이터와 혼동하면 안 된다. 금융 관측일은 2026-11-04, 학습일은 별도다.
- test에서 검증한 실제 AI·사진·Discord 성공은 공식 팀 서버의 키/상태/렌더러 연결까지 자동 검증한 것은 아니다.
- 공식 스케줄러 설정은 변경하지 않는다. 배포 환경에서 오전 8시 정기 실행을 별도 연결해야 하며 실제 시각의 수신 검증은 남아 있다.
- 홈의 기존 AI 호출은 기존 FactChat 설정을 사용한다. 백엔드에만 키를 넣으면 Node의 홈 브리핑까지 자동 연결되지는 않는다.

## 검증
- root TypeScript 검사, 실제 ZIP+팀 패치를 적용한 UI 빌드, API 번들 성공.
- 기존 45개 파일 344개 회귀 테스트 통과. 기존 기기 식별값 이전 검사는 추가로 수행한다.
- 새로운 CI는 기존 팀 패치와 금융 학습 패치를 함께 적용해 실제 배포 소스를 빌드한다.
