## 시세 제공처 (실시간 연결)

| 순서 | 제공처 | 실시간성 | 키 | 비고 |
|---|---|---|---|---|
| 1 | **한국투자증권 KIS Open API** | 웹소켓 `H0STCNT0`로 **체결 즉시**(화면에 '실시간 체결'), 연결 전엔 REST 현재가 3초 간격 | 필요(무료, 계좌 개설) | 공식 API. 현재가 `FHKST01010100`, 지수 `FHPUP02100000`, 일봉 `FHKST03010100`. 토큰은 파일 캐시(발급 횟수 제한 대응) |
| 2 | 네이버 금융 polling | 3초 간격 다시 받기 | 불필요 | **비공식 경로** — 형식 변경·차단 가능, 운영 서비스엔 권장하지 않음 |
| 3 | Yahoo Finance | 지연(약 20분 이상) | 불필요 | 비공식. 일봉(변동성 계산)도 여기서 보완 |
| — | 예시 시세(`demo`) | 5초마다 바뀌는 연습용 숫자 | 불필요 | 화면·카드에 '예시 시세' 표시 |

- `auto`: KIS 키가 있으면 1→2→3, 없으면 2→3. 실패한 종목만 다음 제공처로 넘기고, 화면·카드에는 **실제로 쓴 제공처와 기준 시각**을 표시합니다. 가짜 숫자로 채우지 않습니다.
- 화면 실시간 갱신: 서버 → 브라우저 **SSE(`/api/stream`)** 로 보고 있는 종목을 제공처 주기(3초/30초)에 맞춰 밀어줍니다. 끊기면 15초 새로고침으로 자동 대체. 가격이 바뀌면 행이 깜빡여요.
- 지수: 코스피·코스닥(KIS/네이버/Yahoo), 해외: S&P500·나스닥·원/달러(Yahoo, 직전 마감).

## 카드뉴스

### 데일리 카드뉴스 (매일 Discord로 — 보내기 버튼 없음)
배움 탭 → 오늘의 카드뉴스 → 켜기(공용 채널 전송 정보 동의) → 받는 시각 선택. 서버가 30초마다 확인해 시각이 되면 4장을 만들어 보내고, 실패하면 10분 간격 하루 3번까지 자동 재시도합니다.

1. **오늘의 시장**: 코스피·코스닥·원/달러, 상승·하락 종목 수(KIS), 밤사이 미국 증시
2. **내 보유 종목**: 모의 보유 종목별 등락·평가손익, 오늘 평가 변화(보유가 없으면 관심 종목)
3. **왜 움직였을까**: 가장 크게 움직인 종목(하락 우선)의 원인 분석 — 확인된 사실 / 가능한 요인(강함·보통·약함) / 관련 기사 제목 / 한 줄 정리
4. **오늘의 한 걸음**: 연속 학습일, 오늘의 퀴즈(정답은 앱에서), 다음 레슨 → 앱 재방문 유도

서버에 저장되는 건 모의 보유 종목·관심 종목·학습 진행·닉네임뿐이며(생활비 정보 없음), 끄면 서버 구독도 삭제됩니다.

### '왜 움직였을까' 분석 방식 (`server/lib/explain.ts`)
숫자 비교는 코드로, 원인은 단정하지 않습니다.
- 코스피와 같은 방향·크기 → **시장 전체 요인**(비중에 따라 강함/보통/약함)
- 같은 업종 종목(반도체: 삼성전자↔SK하이닉스 등) 동반 → **업종 요인**
- 시장 대비 ±1.5%p 이상 차이 + 업종으로 설명 안 됨 → **종목만의 요인**, 공시·실적 확인 권유
- 전날 나스닥 ±1% 이상 & 기술·반도체·플랫폼 → **미국 기술주 흐름**
- 원/달러 변동(해외 ETF는 직접 요인, 국내 종목은 '해석되기도' 수준의 약한 요인)
- 거래량 20일 평균 대비 배수, 최근 3일 기사 제목의 부정/긍정 표현
- 신호가 없으면 "원인을 확인하지 못했어요"라고 표시. `ANTHROPIC_API_KEY`가 있으면 위 사실만으로 2~3문장을 다듬고, 사실에 없는 % 숫자가 나오면 버리고 규칙 문장을 씁니다.

### 모의 체결 카드뉴스
매수·매도 체결 직후 자동 생성(내 행동·변동성·왜 움직였을까·복기), 데일리를 켜고 '체결 카드도 보내기'가 켜져 있으면 자동 전송. 실패 시에만 '지금 다시 시도'.
